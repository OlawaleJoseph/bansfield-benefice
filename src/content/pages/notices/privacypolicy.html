User anonymity and personal information

The Bansfield Benefice web server records all file access requests for its files when serving up web pages. These logs do not capture personal information but do capture the user's IP address. These log files are maintained on the server to allow anonymous aggregated usage of the website.

No attempt will be made to identify individual users except where there is a reasonable suspicion that unauthorised access to systems is being attempted. As a condition of use of this site, all users must give permission for the Bansfield Benefice to use its access logs to attempt to track users who are reasonably suspected of gaining, or attempting to gain, unauthorised access.

All log file information collected by the Bansfield Benefice website is kept secure and no access to raw log files is given to any third party.

The Bansfield Benefice website sets cookies details of which can be found on the Cookie Policy page.

To inform people about church services, events, fund raisers and benefice updates the Bansfield Benefice maintains a Mailing List to which people subscribe themselves. An individual can unsubscribe themselves whenever they wish from this mailing list by using the unsubscribe link in the emails sent.

Electoral Rolls of individuals associated with each of the seven parishes of the Bansfield Benefice are also maintain by the Electoral Roll officer for each parish. Each individual must contact the electoral Roll Officer to have their name added or removed from their Parish Electoral Roll. This can be done at any time.
